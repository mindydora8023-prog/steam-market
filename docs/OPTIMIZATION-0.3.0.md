# 0.3.0 优化与验证记录

完成时间：2026-11-14，Asia/Shanghai。

## 已交付

### 报价准确性

- 修复十进制手续费浮点下溢、正算基数未规范化，以及 1% 费率歧义；新增有界穷举验证费用反算最大可达值。
- 备选价返回目标、实际可达买家价、对应到手价和是否精确可达；不再把手续费跳档下的不可达值当成精确价格。
- 四种挂单策略基于同一份行情返回完整费用和格式化金额；页面切换方案不新增行情访问。
- 最低挂单高于中位价 15% 以上只给出差价提示，撤销此前缺少依据的强制降价规则。显式选择中位价或压最低价仍按对应策略执行。
- 非整数 App ID、降价单位和未知币种返回参数错误，不截断或静默回退到无币种标记。

### 历史数据

- 同币种保持原始历史价格，修复原先无条件锚定当前价格造成历史曲线被改写的问题。
- 跨币历史保留比例锚定估算并明确来源、方法和非汇率性质。
- 清理异常时间、价格与成交量，去重排序，按 UTC 日和成交量加权聚合中位样本。
- 区间统计提供样本数、覆盖时间、成交量及完整性；起点样本不足不生成区间涨跌结论。
- 图表按容器宽度重绘，手机刻度保持可读；明确当前中位价/最低价基准，支持键盘、触摸、等价表格和 CSV。

### 性能与可靠性

- 同键搜索、价格、历史请求合并；搜索数量进入缓存键；刷新不误删满缓存中的其他项。
- 修复缓存历史读取与强制刷新的同事件轮合并问题。
- 搜索元数据与报价请求并行；四策略复用行情。
- 429 冷却跨接口共享，尊重 Retry-After 秒数和日期；页面倒计时期间暂停刷新。
- 队列深度/等待、HTTP 重定向全链路、代理 CONNECT/TLS、浏览器请求均设上限。
- 限制压缩前后响应大小，处理滴流连接；跨源重定向清理凭据，验证协议和 Cookie 归属。
- 静态资源提供 ETag/304/HEAD，校验编码路径、ADS、真实路径及 junction 越界；请求 URL 限制 8192 字节。

### 日常使用

- 支持粘贴 Steam 市场链接，自动解析游戏和完整市场名；兼容自定义 App ID。
- 搜索具备取消、防抖、旧响应归属检查、键盘选择、中文输入法保护和字段级错误。
- 买家价和到手价相邻，显示费用占比、币种、行情获取时间和缓存来源。
- 复制纯数字的买家价或到手价；分享链接保留费率、策略、数量和历史范围。
- 数量合计按每件费用取整后累加；收藏最多 30 个；最近记录最多 20 条，支持恢复条件与撤销清空。
- 更新中/条件变化/失败保留旧报价，醒目标记过期并拦截复制；提供取消、重试与可用策略恢复。
- 浏览器存储损坏或被禁用时保持查询可用，收藏保存失败明确提示。
- 减少标题与重复价格占位，手机游戏/币种并排；上架说明折叠，保留减少动效与可见焦点。
- 图片加载等待或失败时保留首字母占位，避免空白图标。

### 启动与进程

- 健康响应增加稳定应用标识、版本、根目录和 PID。
- CheckOnly 只检查，不再启动；启动器以有界互斥锁处理并发启动，使用绝对脚本路径并检查提前退出。
- 端口被占用时报错，避免浏览器打开另一个服务或端口漂移。
- 停止前精确核对 Node 的完整入口路径，重查创建时间，处理多监听 PID；不模糊匹配其他 Node 进程。

## 实际边界

价格仍依赖 Steam 公开接口；历史公开页面改版或限流时可能缺失。跨币种历史为估算序列，币种最低费为现有模型，均需以 Steam 实际上架金额为准。本轮保留只读查价工作流，未加入自动交易、后台轮询、账号凭据或没有已验证数据源的订单深度展示。

没有创建 Git 提交或推送。该目录不是 Git 仓库，因此复核使用逐文件读取和运行测试，没有声称取得 Git diff。
