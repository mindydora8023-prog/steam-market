# Steam 市场价格助手

本地运行的 Steam 社区市场查价工具。查询当前最低挂单、近期中位成交与成交量，比较四种挂单方案，估算每件到手及手续费，再由你在 Steam 手动上架。

版本 **0.3.0**，Node.js **18.17+**，应用运行零第三方依赖。使用公开市场数据，不需要 Steam 登录或 Cookie。

[桌面截图](docs/screenshot-v030-desktop.png) · [手机截图](docs/screenshot-v030-mobile.png) · [0.3.0 优化与验证记录](docs/OPTIMIZATION-0.3.0.md)

## 快速启动

```sh
git clone https://github.com/mindydora8023-prog/steam-market.git
cd steam-market
npm start
```

打开 [http://127.0.0.1:8787](http://127.0.0.1:8787)。Windows 也可以双击 `start.cmd`。应用运行只需 Node.js，修改后端代码后需重启服务。在启动服务的终端按 Ctrl+C 停止。

```sh
node app/server.mjs --proxy http://127.0.0.1:7890
node app/server.mjs --proxy none
```

Windows 上可以用 `scripts/open-app.ps1` 检查服务并打开页面。默认使用本地地址。部署在其他地址时传入 `-BaseUrl`，可包含路径前缀。`-CheckOnly` 输出健康检查结果。

```powershell
pwsh -File .\scripts\open-app.ps1 -CheckOnly
pwsh -File .\scripts\open-app.ps1 -BaseUrl https://example.org/steam/
```

## Linux 部署

带 systemd 的 Linux 可从仓库根目录执行安装。服务默认监听 `127.0.0.1:8787`，可按需通过 `deploy/Caddyfile` 配置反向代理。

```sh
sudo env PAYLOAD_DIR="$PWD" bash deploy/install.sh
```

## 日常查价

1. 选择游戏与币种。也可以直接粘贴 Steam 物品市场链接，自动识别游戏和完整市场名，包括自定义 App ID。
2. 输入两个以上字符会显示候选。上下键选择，Enter 查询，Escape 收起。中文输入法组合期间不会误发查询。
3. 查看金色的**买家支付价**和旁边绿色的**预计到手**。报价附近会显示币种、行情获取时间及缓存状态。
4. 在“挂单方案对比”中比较智能推荐、压最低价、持平最低价、参考中位价。每种方案显示买家价与到手价；点击切换使用同一份行情，无需重新访问 Steam。
5. “复制买家价”和“复制到手价”复制纯数字金额，例如 `3.60`，方便填入 Steam 表单。
6. 点击“在 Steam 市场打开”，核对物品和实际费用，手动上架与确认。

其他功能：

- **数量合计**：同价出售多件时的买家支付、卖家到手和总手续费。费用按每件取整后相加，假设每件都能按该价格成交。
- **收藏物品**：最多 30 个，点击重新查价，可取消收藏。
- **最近计算**：保留最多 20 条，不同币种分开；恢复时带回策略与费率。清空后可撤销。
- **复制查询链接**：携带物品、游戏、币种、策略、降价幅度、费率、数量和历史区间，方便收藏。
- **快捷键**：非输入状态按 `/` 聚焦搜索框。
- **取消与恢复**：可取消等待中的查询。更新失败保留旧结果，明确标记过期并拦截复制，输入内容保留。
- **限流倒计时**：Steam 返回 429 时显示等待时间，冷却期间暂停刷新。

设置、收藏和记录保存在浏览器 localStorage。隐私模式或浏览器限制存储时，查询仍可用；收藏保存失败会明确提示。浏览器之间不自动同步。

### 高级设置

默认低一个最小货币单位（CNY 为 ¥0.01，JPY 为 ¥1），Steam 费率 5%、发行商费率 10%。可调整降价幅度及两项费率；持平策略会隐藏降价幅度。费率以 Steam 上架页面为准。

分享链接示例：

```text
http://127.0.0.1:8787/?name=Clutch%20Case&app=730&currency=23&strategy=smart&undercut=1&steamFee=5&publisherFee=10&days=180&quantity=1
```

## 报价规则

应用的所有挂单价均为**买家支付价**。Steam 与发行商费从卖家到手金额计算，然后反算可实现的买家价。金额按最小货币单位处理，百分比计算使用十进制整数运算，避免浮点乘法少算一分。

| 策略 | 计算依据 |
| --- | --- |
| 智能推荐 | 通常按最低挂单减降价幅度；最低挂单小于中位价一半时，沿用低价异常保护，参考中位价 |
| 压最低价 | 按最低挂单减降价幅度，不做中位价异常保护 |
| 持平最低价 | 以最低挂单为目标，反算不高于目标的可实现价格 |
| 参考中位价 | 直接参考中位成交，不减降价幅度 |

最低挂单高于中位成交 15% 以上时，智能推荐给出价差提示，**不会仅凭该阈值自动压低卖家收益**。中位成交并非未来成交保证；四种策略同时列出便于自行权衡。

Steam 手续费取整会让某些买家价不可实现。报价与备选价显示反算后的实际可达值，并给出取整提示，而不是把不可实现的目标当作精确挂单价。

### 低价物品与最低手续费

CNY 当前模型：Steam 和发行商每笔各最低 ¥0.07，最低可挂买家价 ¥0.21。因此买家支付 ¥0.29 时，按默认两项费率预计到手 ¥0.15，而非按单纯 15% 计算。

JPY 最低费按每笔 2 日元处理。其他币种按一个最小货币单位兜底。不同游戏和地区的实际费用规则可能不同，请核对 Steam 的“买家支付 / 您将收到”。

## 历史走势

报价后异步加载，不阻塞报价结果。支持 30 / 90 / 180 / 365 天、区间价格范围、分位和涨跌参考。

- 数据来自市场页面公开的成交中位样本，按 UTC 日和成交量加权聚合；这是**中位样本的日聚合值**，并非真实的每日成交中位数。
- **同币种保留历史原价**，不会为了贴合当前报价去缩放历史。
- 跨币种时，使用“当前选中币种价格 / 历史末值”进行比例锚定估算。它不是汇率换算，也不是逐日汇率；页面与 CSV 均标出估算性质。
- 显示交易日样本数和覆盖天数。缺失日期不补造价格；区间起点缺少样本时，不计算该区间涨跌幅。分位只基于已有的日样本，不按所有成交笔数统计。
- 手机按容器宽度重新绘图。触摸或悬停查看日期、价格和成交量；键盘左右键逐点查看，Home / End 跳到两端。
- 可展开等价数据表，或导出当前区间 CSV。CSV 含日期、数值、币种、成交量和估算标记。

历史数据缺失、Steam 限流或页面结构变化时，会显示独立错误与重试入口，当前报价仍保留。

## 网络、缓存与等待边界

启动时依次检查显式代理、`HTTPS_PROXY` / `HTTP_PROXY`、本机 7890 / 7897 / 10809 端口。仅支持 HTTP CONNECT 代理，Clash 使用 HTTP / mixed 端口。

| 数据 | 内存缓存 |
| --- | --- |
| 搜索候选 | 5 分钟，按游戏、关键词、数量隔离 |
| 当前价格 | 60 秒 |
| 历史页面 | 10 分钟 |
| 无报价结果 | 2 分钟 |

- 同键并发请求合并，避免多次相同上游访问。
- 搜索元数据和价格并行获取；方案比较复用一份快照。
- “刷新”绕过缓存，刷新同键不会误删其他键。
- 429 冷却在搜索、报价与历史间共享；冷却中缓存仍可供后端读取。
- 请求队列和等待均有上限。网络全链路、代理连接与响应大小都有边界；不会无限等待或无限解压。
- 浏览器请求也有 deadline 与取消，旧请求响应不会覆盖新输入。

右上角指示的是**本地服务状态和连接模式配置**，不是已经验证 Steam 连通。网络问题会在查询时明确显示。

## 开发与验证

```powershell
npm test
npm run check
npm run test:ui
```

前两项可离线运行，覆盖手续费、币种、报价、历史统计、请求限流、HTTP、API 与静态服务。Windows 启动脚本测试需要 PowerShell 7（`pwsh`）。

浏览器测试使用 Playwright Core、Chromium 或 Edge 及离线测试行情，覆盖搜索、复制、策略切换、收藏、图表、错误恢复和移动端布局。可在项目目录运行 `npm install --no-save --package-lock=false playwright-core`，也可通过 `PLAYWRIGHT_MODULE` 指定现有安装的 `index.mjs`。按需设置 `BROWSER_EXECUTABLE`，默认在 Windows 使用 Edge。截图默认写入 `.ui-evidence/`，可通过 `UI_EVIDENCE_DIR` 修改。

主要文件：

```text
app/api.mjs                 报价、方案对比、历史聚合与统计
app/steam.mjs               Steam 公共接口、缓存、限流与请求合并
app/history.mjs             历史页面解析
app/app.mjs                 请求入口与健康标识
app/static.mjs              静态资源、条件缓存及路径限制
app/public/app.js           搜索、报价、收藏、图表交互
app/public/ui-utils.js      输入解析、数值复制、请求边界等纯工具
app/public/styles.css       响应式界面
app/public/locale/zh.json   动态中文文案
lib/fees.js                 手续费正反算
lib/quote.js                四种报价策略
lib/http.js                 HTTP、代理、响应上限与 deadline
scripts/browser-smoke.mjs   隔离浏览器验证
DESIGN.md                  界面与状态契约
```

服务默认仅监听 `127.0.0.1`，不接收 Steam 凭据、不登录、不创建或撤销挂单。价格和费用均作参考，最终以 Steam 市场及上架页面为准。
